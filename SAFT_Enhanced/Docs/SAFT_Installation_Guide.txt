## PASUL 3: INTEGRARE GRADUALA (RECOMANDAT)

Varianta A - Integrare Graduala cu Bridge:
```foxpro
* In programul principal:
SET PROCEDURE TO SAFT_Compatibility_Bridge.prg ADDITIVE

* Verificare compatibilitate:
IF SAFT_Check_Enhancement_Compatibility()
    ? "Enhanced components available"
ELSE
    ? "Using original architecture"
ENDIF

* Executie cu migrare automata:
llSuccess = SAFT_Migrate_To_Enhanced(tdData1, tdData2, tcTipDeclaratie, tnSegmente)
```

Varianta B - Integrare Directa:
```foxpro
* Include toate fisierele:
SET PROCEDURE TO SAFT_DI_Container.prg ADDITIVE
SET PROCEDURE TO SAFT_ConfigManager.prg ADDITIVE  
SET PROCEDURE TO SAFT_Exception_Hierarchy.prg ADDITIVE
SET PROCEDURE TO SAFT_HandlerFactory.prg ADDITIVE
SET PROCEDURE TO SAFT_PerformanceMonitor.prg ADDITIVE
SET PROCEDURE TO SAFT_AsyncProcessor.prg ADDITIVE
SET PROCEDURE TO SAFT_Enhanced_Main.prg ADDITIVE
SET PROCEDURE TO SAFT_Advanced_Classes.prg ADDITIVE
SET PROCEDURE TO SAFT_Helpers.prg ADDITIVE

* Apel direct:
llSuccess = SAFT_Enhanced_Main(tdData1, tdData2, tcTipDeclaratie, tnSegmente)
```

## TROUBLESHOOTING:

Problema: "File not found" errors
Solutie: Verificati ca toate fisierele .prg sunt in acelasi director

Problema: "Class not found" errors  
Solutie: Asigurati-va ca SET PROCEDURE TO este executat pentru toate fisierele

Problema: Performance scazuta
Solutie: Ajustati BatchSize in SAFT_Config.json

Problema: Memorie insuficienta
Solutie: Activati async processing si reduceti batch size
